# DigiNOSIA · Portfolio

Web estática (HTML, CSS y JavaScript sin dependencias ni compilación). Páginas por ancla: `#inicio`, `#proyectos`, `#especialidades`, `#metodologia`, `#sobre`, `#perfil`, `#contacto` y una ficha por proyecto (`#hisdatawiki`, `#codisalud`…).

## Estructura
- `index.html`: marcado, metadatos y datos estructurados (JSON-LD).
- `assets/css/styles.css`: tokens, componentes, animaciones y accesibilidad.
- `assets/js/app.js`: datos de proyectos y perfil, rutas por ancla, panel de accesibilidad, lector por bloques, animaciones y gráficos SVG.
- `docs/referencias-diseno/`: capturas del diseño original del perfil.

## Accesibilidad
Panel «Accesibilidad»: perfiles rápidos (baja visión, dislexia, daltonismo, concentración, motricidad, lector de pantalla), tipografía y espaciado, temas, filtros de color, color de fondo de lectura, regla de lectura, botones y cursor grandes, lector en voz alta por bloques con controles (anterior, pausa, siguiente, detener, velocidad, tono, volumen) y navegador de títulos. Atajos: `?` ayuda, `/` buscar, `g` + letra para navegar.

## Publicar
Sube la carpeta a GitHub Pages o a cualquier alojamiento estático. Las fuentes se cargan desde Google Fonts.
