# CV Landing · Sara López-Figueredo

Proyecto estático (sin build). Abrir `index.html` o servir la carpeta con cualquier servidor web.

- `index.html`: estructura y contenido (HTML semántico, sin CSS ni JS en línea).
- `css/`: `styles.css` base · `formadora.css` acreditaciones · `formacion.css` dashboard de formación · `experiencia.css` trayectoria y titulaciones · `a11y.css` accesibilidad, contraste e impresión · `inline.css` estilos antes en atributos `style`.
- `js/`: `boot.js` · `main.js` (animaciones, navegación, copiar correo, imprimir) · `formadora.js` y `formacion.js` (buscadores).
- `assets/img/`: imágenes.

Datos: resoluciones del Registro de Formadores (solo concedidas), Excel de cursos, vida laboral, hojas de servicios, contratos y certificados.
