# CV Landing · Sara López-Figueredo

Proyecto estático (sin build). Abrir `index.html` o servir la carpeta con cualquier servidor web.

- `index.html`: solo estructura y contenido (HTML semántico, sin CSS ni JS en línea).
- `css/styles.css` diseño base · `formadora.css` acreditaciones · `formacion.css` dashboard de formación · `a11y.css` accesibilidad, contraste e impresión · `inline.css` estilos antes en atributos `style`.
- `js/boot.js` detección JS · `main.js` animaciones, navegación, copiar correo, imprimir · `formadora.js` buscador y filtros de acreditaciones · `formacion.js` buscador de cursos.
- `assets/img/` imágenes (antes incrustadas en base64).

Datos: acreditaciones de formador según las resoluciones del Registro de Formadores (solo concedidas); cursos y titulaciones según el Excel de cursos.
